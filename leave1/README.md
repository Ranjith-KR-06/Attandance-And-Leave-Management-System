# Attendance And Leave Management System

## 📌 Project Overview
The **Attendance And Leave Management System** is a web-based application developed to automate and simplify attendance tracking and leave management processes. The system helps organizations, institutions, or companies manage attendance records efficiently while reducing manual paperwork and errors.

This project provides features for users to mark attendance, apply for leave, and manage records digitally through an easy-to-use interface.

---

## 🚀 Features
- User Login & Authentication
- Attendance Tracking System
- Leave Application Management
- Leave Approval & Rejection
- Attendance and Leave History
- Admin Dashboard
- Database Management
- Responsive User Interface
- Secure Record Handling

## ⚙️ Installation Guide

### Prerequisites
Make sure the following software is installed:
- XAMPP / WAMP Server
- PHP
- MySQL
- Web Browser

---

### Steps to Run the Project

#### 1. Clone the Repository
```bash
git clone https://github.com/your-username/Attendance-And-Leave-Management-System.git
```

#### 2. Move Project Folder
Copy the project folder into the `htdocs` directory inside XAMPP.

Example:
```bash
C:\xampp\htdocs\
```

#### 3. Start Server
Open XAMPP Control Panel and start:
- Apache
- MySQL

#### 4. Import Database
- Open phpMyAdmin
- Create a new database
- Import the SQL file from the `database` folder

#### 5. Run the Project
Open the browser and enter:
```bash
http://localhost/Attendance-And-Leave-Management-System
```
