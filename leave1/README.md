# Attendance And Leave Management System

## Overview
Attendance And Leave Management System is a web-based application developed to automate attendance tracking and leave management processes. The system helps reduce manual work, improve accuracy, and manage records efficiently.

## Features
- User Authentication
- Attendance Management
- Leave Application System
- Leave Approval/Rejection
- Attendance & Leave History
- Admin Dashboard
- Database Record Management
- Responsive User Interface

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
